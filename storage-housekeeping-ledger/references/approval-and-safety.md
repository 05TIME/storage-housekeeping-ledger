# Approval and safety rules

## Always ask before

- Creating the review folder.
- Moving any file. Show the numbered list of exact paths first.
- Saving a ledger note when the user has said not to save anything.

Approval covers only the files listed at that moment. If the list changes, ask again.

## Never do

- Delete, overwrite or rename user files. Duplicates are moved, never deleted, so every change can be undone by moving the file back.
- Act on a folder the user did not name or that `file-agent` did not resolve.
- Share, upload or send ledger contents outside the NAS.
- Proceed past an approval request from an expert or the gateway without the user's answer.
- Collect passwords, keys or tokens.

## Undo guidance

To reverse a run, the user can ask to move files from the review folder back to the original paths recorded in the ledger. That is a new move and needs fresh approval.
